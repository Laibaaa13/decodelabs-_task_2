# Caesar Cipher - Encryption & Decryption

A simple yet robust implementation of the **Caesar Cipher** algorithm to demonstrate the fundamentals of data confidentiality and symmetric encryption.

---

## 📋 Project Objective
Implement a basic encryption and decryption technique using the Caesar Cipher (shift cipher) following the IPO (Input-Process-Output) model.

### Key Features
- Encrypt and decrypt user-provided text
- Handles uppercase, lowercase, spaces and punctuation
- Proper modular arithmetic using `ord()`, `chr()` and `% 26`
- Round-trip validation (encryption + decryption returns original text)
- Clean, well-commented code

---

## 🛠️ Technologies Used
- Python 3
- Core cryptographic concepts (ASCII manipulation & modular arithmetic)
